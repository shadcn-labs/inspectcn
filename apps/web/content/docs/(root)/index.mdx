**inspectcn** is a Chrome extension to inspect and extract shadcn-style theme tokens from any website, then bring them into your project.

## What you can do

- Inspect the active theme tokens, grouped into surfaces, semantic colors, charts, and sidebar colors.
- Copy individual tokens or the current theme as CSS.
- Capture a theme and reuse it on another page.
- Apply a captured theme to localhost and reset the preview when you are done.

## How it works

Open the inspectcn badge on a website to read its active theme. inspectcn samples visible elements and reads their computed CSS custom properties, including values inside nested theme wrappers.

It reads the page's current light or dark theme. To inspect the other mode, switch the website's theme and use **Reread**.

Sites without shadcn-style CSS variables may show missing tokens. inspectcn does not turn every color on a page into a complete theme.

## Extension tech stack

- **WXT** — browser extension development and packaging.
- **React + TypeScript** — the inspector UI and extension logic.
- **Tailwind CSS** — styling.
- **shadcn/ui + Base UI** — UI components and accessible primitives.
- **Lucide** — icons.

## Early development

inspectcn is still in early development. Theme detection can be inaccurate on sites with unusual theme systems, nested overrides, or overlays. Review the captured values before using them in your project.

More features are planned, including additional color formats, editing colors, font capture, sharing presets, and previews beyond localhost.

If you find an issue, [report it on GitHub](https://github.com/shadcn-labs/inspectcn/issues) with the website URL and a short description of what went wrong.
