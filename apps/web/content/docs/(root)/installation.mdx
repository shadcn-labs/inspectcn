## Add to Chrome

Install [inspectcn from the Chrome Web Store](https://chromewebstore.google.com/detail/inspectcn/jmpjlakfdenblabkjbdcepoolnphdgen), then open or reload the website you want to inspect.

## Inspect and copy

1. Click the inspectcn badge on the page.
2. Review the detected tokens and their color previews.
3. Use **Copy** beside a token to copy its CSS declaration, or copy the current theme as a CSS block.
4. If the website changes theme, use **Reread** to refresh the values.

Paste the generated CSS into your project's theme stylesheet and review it before replacing existing values.

## Capture and preview on localhost

1. On the source website, click **Capture** to save the active theme.
2. Open your project on localhost and click the inspectcn badge.
3. Select **Apply to localhost** to preview the captured theme.
4. Select **Reset local** to restore the page's original theme.

Capturing another theme replaces the saved capture. **Copy saved** copies the captured CSS, and **Clear saved** removes the saved capture.

Applying a theme previews CSS variables in the browser; it does not edit your project files. To keep the theme, copy its CSS into your project.

## Where it works

Theme inspection depends on the CSS variables a website exposes. Missing tokens are shown as **Not found on this page**.

Local previews are available on HTTP pages at `localhost`, `127.0.0.1`, and `0.0.0.0`. Chrome restricts extensions on internal browser pages and the Chrome Web Store.

## Early development

inspectcn is still in early development, and more features are being developed. If detection or a preview looks wrong, reset the preview and [report the issue](https://github.com/shadcn-labs/inspectcn/issues).
